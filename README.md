# GP2
GP2 is a platformer speedrunning game based on Celeste.
## Requirements
- Git
- Godot 3.6 (No, Godot 4 doesn't work)
## Installation
For now, you can get it through here.
1.  ```bash
    git clone https://github.com/Pauisdev/gato-pija-2
    ```
2.  Open the project up with Godot 3.6
